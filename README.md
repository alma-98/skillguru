# SkillGuru

> **Belajar Terarah, Masa Depan Cerah.**

SkillGuru adalah platform Learning Management System (LMS) modern untuk menyediakan pengalaman pembelajaran digital yang terarah, terukur, dan terintegrasi dengan teknologi AI.

## Technology Stack

### Frontend
- React
- TypeScript
- Vite

### Backend
- Java
- Spring Boot
- Maven
- Spring Security
- JWT
- Swagger / OpenAPI

### Database
- PostgreSQL

### Storage
- Object Storage

### AI
- AI Recommendation
- AI Quiz
- AI Learning Assistant
- AI Skill Analysis

## Core Modules

- Dashboard
- Courses
- Materials
- Videos
- Quizzes
- Assignments
- Certificates
- Users
- Mentors
- Categories
- Discussions
- Progress
- Payments
- Notifications
- Reports
- Settings
